# 트라이팟 송

https://arngard.github.io/tripod-song/

나스닥100의 이동평균, VIX 평균, 52주 낙폭으로 3배, 1.5배, 현금 사이의 배분을 정하는 규칙 기반
전략의 일별 판정을 공개하는 정적 사이트다. 나스닥 테스트와 침체장 테스트 탭은 진입 시점에 따라 플레이버 다섯과
QQQ, TQQQ 보유의 원화 평가금이 어떻게 갈리는지를 지난 자료로 계산해 보인다. 이 저장소는 평일 미국 장 마감 뒤 자동으로 생성된
결과물만 담으며, 매번 덮어쓴다.

이 페이지는 한 개인이 규칙 기반 전략을 시험하며 매일 기계적으로 계산해 공개하는 판정 기록이다. 매수나 매도를 권하지 않는다. 투자 판단과 그 결과의 책임은 각자에게 있다. 백테스트 지표와 테스트 탭의 수치는 지수 종가로 합성한 과거 경로의 계산값이다. 침체장 테스트 탭의 가상 침체장은 다른 시장의 움직임을 빌린 가상 경로다. 판정에는 자료 오류나 지연이 있을 수 있다. 자료: Yahoo Finance, FRED.
