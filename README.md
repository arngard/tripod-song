# 트라이팟 송

https://arngard.github.io/tripod-song/

나스닥100의 이동평균, VIX 평균, 52주 낙폭으로 3배, 1.5배, 현금 사이의 배분을 정하는 규칙 기반
전략의 일별 판정을 공개하는 정적 사이트다. 둘째 탭(트라이팟 플레이버 비교)은 사상 최고가에 진입했을 때 플레이버 넷과
QQQ, TQQQ 보유의 원화 평가금 경로를 지난 자료로 계산해 보인다. 이 저장소는 평일 미국 장 마감 뒤 자동으로 생성된
결과물만 담으며, 매번 덮어쓴다.

이 페이지는 한 개인이 규칙 기반 전략을 시험하며 매일 기계적으로 계산해 공개하는 판정 기록이다. 매수, 매도 권유가 아니며, 투자 판단과 그 결과의 책임은 각자에게 있다. 백테스트 지표와 트라이팟 플레이버 비교 탭의 수치는 지수 종가로 합성한 과거 한 경로의 계산값이고, 판정에는 자료 오류나 지연이 있을 수 있다. 자료: Yahoo Finance, FRED.
