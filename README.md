# 트라이팟 송

https://arngard.github.io/tripod-song/

나스닥100의 이동평균, VIX 평균, 52주 낙폭으로 3배, 1.5배, 현금 사이의 배분을 정하는 규칙 기반
전략의 일별 판정을 공개하는 정적 사이트다. 나스닥 테스트와 닛케이 테스트 탭은 진입 시점에 따라 플레이버 다섯과
QQQ, TQQQ 보유의 원화 평가금이 어떻게 갈리는지를 지난 자료로 계산해 보인다. 이 저장소는 평일 미국 장 마감 뒤 자동으로 생성된
결과물만 담으며, 매번 덮어쓴다.

이 페이지는 아릉이 규칙 기반 전략을 연구하며 매일 기계적으로 계산해 공개하는 연구 결과다. 판정과 행동 문장은 그 규칙이 내는 계산 결과이며 투자 권유가 아니다. 이를 참고해 매매하는 행위와 그 결과의 책임은 매매하는 본인에게 있다. 백테스트 지표와 테스트 탭의 수치는 지수 종가로 합성한 과거 주가로 계산한 값이다. 닛케이 테스트 탭의 주가는 나스닥100이 닛케이225처럼 움직였다고 가정한 가상의 주가다. 판정에는 자료 오류나 지연이 있을 수 있다. 자료: Yahoo Finance, FRED.
